    6. Kapitel 5 - Der [Angular]-Client der Anwendung [RdvMedecins]

    Dieses Kapitel beschreibt Datei für Datei den Inhalt des Ordners [rdvmedecins-angular-client], der diesem Dokument beiliegt, im durchgängig in diesem Kurs verwendeten Format: zeilenweise nummerierter Quellcode, gefolgt von einem Abschnitt mit dem Titel „Kommentieren wir diesen Code:“. Jeder Projektordner enthält außerdem eine eigene Datei README.md.

    6.1. Architekturüberblick

    Wie im ursprünglichen Dokument folgt der Client einer Schichtenarchitektur, die wir hier als V-C-Services (View-Controller-Services) bezeichnen:

    Ein Unterschied in der Terminologie verdient Beachtung: In AngularJS 1.x waren die View (das HTML-Template) und der Controller (die zugehörige JavaScript-Klasse) zwei getrennte Einheiten, die über $scope verbunden waren. In [Angular] sind sie in einer einzigen Einheit zusammengefasst, der Komponente (siehe vorheriges Kapitel) – deshalb sprechen wir im Folgenden einfach von „Komponenten“, wo das ursprüngliche Dokument zwischen View und Controller unterschied.

    Wie im ursprünglichen Dokument kommunizieren Komponenten NIEMALS direkt mit dem Server: Diese Rolle ist ausschließlich der Service-Schicht vorbehalten. Dies ist ein Entwurfsprinzip, das für AngularJS 1.x und [Angular] gleichermaßen gilt – es hat sich nicht geändert.

    6.2. Projektbaum

    Diese Struktur folgt direkt dem Ablauf des ursprünglichen Dokuments (Login, Auswahl von Arzt/Tag, Terminkalender anzeigen, Termin vereinbaren), hier lediglich in eigenständigen [Angular]-Komponenten organisiert statt in getrennten Controllern und Views von AngularJS 1.x.

    Bootstrap wird in allen Views verwendet ([node_modules/bootstrap/dist/css/bootstrap.min.css], deklariert in angular.json) – eine direkte Weiterentwicklung von Bootstrap 3, das bereits im ursprünglichen Dokument verwendet wurde.

     this.error.set(null);

   onSearchSchedule(criteria: { doctorId: number; day: string }): void {
     this.error.set(null);

     this.lastDay = criteria.day;
     this.loadSchedule();

   onBookingRequest(slot: SlotJson): void {
     this.slotBeingBooked.set(slot);
   }

   onConfirmBooking(choice: { clientId: number }): void {
     const slot = this.slotBeingBooked();
     if (slot === null || this.lastDay === null) {
       return;
     }
     this.appointmentService.addAppointment(this.lastDay, choice.clientId, slot.id)
       .pipe(takeUntilDestroyed(this.destroyRef))

         next: () => { this.slotBeingBooked.set(null); this.loadSchedule(); },

   onCloseBooking(): void {

    6.13. Was außerhalb des Umfangs bleibt oder zurückgestellt wird

    Der „Debug“-Modus (Anzeige des rohen Templates der aktuellen Ansicht) des ursprünglichen AngularJS-1.x-Clients ist ein Feature, das in diesem Port bewusst weggelassen wurde – er wird in einer späteren Phase des Kurses nicht auftauchen (die Begründung dieser Entscheidung finden Sie in Kapitel 6, Fazit). Das Festlegen einer künstlichen Netzwerkverzögerung wird dagegen tatsächlich auf eine spätere Phase verschoben.
